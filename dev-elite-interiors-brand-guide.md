## 2. Design Direction

The website should use the following design philosophy:

-   White space first
-   Deep emerald green for brand identity
-   Gold for selective luxury accents
-   Large, high-quality interior photography
-   Editorial layouts
-   Strong typography hierarchy
-   Calm transitions
-   Intentional spacing
-   Minimal but expressive components
-   Premium product-design principles

### Apple-Inspired, Not Apple-Branded

Use the underlying principles of premium product design:

-   Simplicity
-   Clear visual hierarchy
-   Generous whitespace
-   Product-style storytelling
-   Focus
-   Smooth interactions
-   Fast and quiet animation
-   Strong usability

Do **not** copy:

-   Apple's branding
-   Apple's exact layouts
-   Apple's typography
-   Apple's icons
-   Apple's colors
-   Apple's copy
-   Apple's source code
-   Apple's proprietary assets

The website must remain visibly and unmistakably **Dev Elite
Interiors**.

The website background should remain white.

  -------------------------------------------------------------------------------
  Token                     Color             Hex               Usage
  ------------------------- ----------------- ----------------- -----------------
  `color-bg-primary`        Pure White        `#FFFFFF`         Main website
                                                                background

  `color-brand-green`       Deep Emerald      `#063F2B`         Primary brand
                                                                color, hero
                                                                sections, buttons

  `color-brand-green-2`     Luxury Green      `#0D6045`         Secondary green,
                                                                hover states,
                                                                supporting
                                                                surfaces

  `color-brand-gold`        Champagne Gold    `#B69A54`         Premium accents,
                                                                logo details,
                                                                fine borders

  `color-brand-gold-soft`   Soft Gold         `#D6C18A`         Subtle borders,
                                                                decorative
                                                                details

  `color-text-primary`      Charcoal          `#1F2924`         Main readable
                                                                text

  `color-text-secondary`    Muted Green Gray  `#65716B`         Secondary text,
                                                                captions

  `color-border`            Soft Neutral      `#E7EAE7`         Dividers, subtle
                                                                borders

  `color-surface-soft`      Soft White        `#F7F8F6`         Light section
                                                                backgrounds
  -------------------------------------------------------------------------------

### Color Hierarchy

Recommended approximate distribution:

-   White: 70--80%
-   Green: 15--25%
-   Gold: 2--5%

### Color Rules

-   White is the default canvas.
-   Deep emerald is the main brand anchor.
-   Gold should be selective, not everywhere.
-   Gold should never become neon yellow.
-   Avoid random blue, purple, orange, or AI-generated gradients.
-   Avoid heavy color overlays on photography.
-   Use green backgrounds for important brand moments and CTAs.
-   Use gold for details, not for large areas.

### Accessibility

-   Use dark green or charcoal text on white backgrounds.
-   Do not use gold as small body text on white.
-   Ensure all text and controls meet accessible contrast requirements.
-   Never rely on color alone to communicate meaning.

## 4. Logo System

### Primary Logo

Gold crown + DE shield + DEV ELITE INTERIORS wordmark.

### Logo Usage

Preferred:

-   Original green/gold logo on white background
-   Suitable reversed logo on deep green background, if created
-   Website header
-   Website footer
-   Official documents
-   Brand presentations

### Clear Space

Maintain a minimum clear space around the logo.

Recommended starting rule:

-   Minimum clear space = approximately 25% of the crown height.

### Minimum Size

Do not reduce the logo so far that:

-   The crown details become unclear
-   The DE monogram becomes unreadable
-   The wordmark loses legibility

### Do Not

-   Stretch or distort the logo
-   Change the crown color randomly
-   Replace green with blue or purple
-   Add unnecessary shadows or glows
-   Use heavy gradients
-   Place the logo on a busy image without a clear background
-   Crop the crown or shield
-   Alter the proportions
-   Use gold as neon yellow

### Asset Requirement

The final implementation should ideally include:

-   Primary logo in SVG
-   Primary logo in PNG
-   Reversed white/gold version, if approved
-   Favicon
-   Monogram-only version
-   Social profile version

## 5. Typography

The logo uses an elegant serif style. The website should preserve that
premium feeling through a serif display font paired with a modern
sans-serif body font.

### Recommended Fonts

#### Display Font

**DM Serif Display**

Use for:

-   Hero headlines
-   Major section headings
-   Editorial statements
-   Brand statements
-   Selected premium highlights

#### Body Font

**Manrope**

Use for:

-   Navigation
-   Body text
-   Buttons
-   Forms
-   Service descriptions
-   Captions
-   UI elements

### Typography Scale

  Style           Desktop     Mobile
  ------------ ---------- ----------
  Display        64--80px   42--52px
  H1             52--64px   36--44px
  H2             40--48px   30--36px
  H3             24--32px   22--26px
  Body Large         20px       18px
  Body           16--18px       16px
  Caption        12--14px   12--14px

### Typography Rules

-   Do not make every heading extremely bold.
-   Do not use oversized headings in every section.
-   Use serif typography selectively.
-   Use sans-serif typography for clarity and usability.
-   Avoid excessive uppercase text.
-   Keep paragraph width approximately 600--680px.
-   Use comfortable line height.
-   Maintain consistent heading rhythm.
-   Ensure headings wrap naturally on mobile.
-   Use subtle letter spacing.
-   Do not use decorative fonts for body copy.

## 19. Spacing and Grid

### Spacing Tokens

  Token           Value Usage
  ------------- ------- -----------------------
  `space-xs`        8px Small gaps
  `space-sm`       12px Labels and icon gaps
  `space-md`       16px Standard spacing
  `space-lg`       24px Component gaps
  `space-xl`       40px Content groups
  `space-2xl`      64px Section spacing
  `space-3xl`      96px Major section padding
  `space-4xl`     128px Large hero spacing

### Layout Tokens

-   Max content width: approximately 1200--1280px
-   Desktop horizontal padding: approximately 48px
-   Mobile horizontal padding: approximately 24px
-   Desktop grid: 12 columns where useful
-   Mobile grid: single-column or intentional two-column compositions
-   Paragraph max width: approximately 600--680px

### Rules

-   Use whitespace intentionally.
-   Do not fill empty areas unnecessarily.
-   Maintain consistent vertical rhythm.
-   Align content deliberately.
-   Do not center every section.
-   Avoid unexpected spacing changes between breakpoints.

## 20. Animation System

### Animation Personality

-   Natural
-   Fast
-   Purposeful
-   Smooth
-   Quiet
-   Responsive

### Approved Animation Types

-   Fade in
-   Subtle slide
-   Staggered content reveal
-   Image reveal
-   Subtle image scale
-   Button hover transition
-   Border transition
-   Scroll reveal

### Recommended Durations

  Interaction             Duration
  ------------------- ------------
  Micro interaction     150--200ms
  Button hover          200--300ms
  Image hover           300--500ms
  Section reveal        500--700ms

### Avoid

-   Bouncing
-   Random floating
-   Constant motion
-   Heavy parallax
-   Long transitions
-   Excessive blur animation
-   Attention-grabbing effects everywhere

### Accessibility

Respect:

``` css
@media (prefers-reduced-motion: reduce) {
  /* Reduce or disable non-essential animation */
}
```

Content must remain usable when animation is disabled.

## 21. Responsive Experience

Do not simply shrink the desktop version.

### Desktop

-   Large editorial layouts
-   Wide photography
-   Spacious navigation
-   Strong typography
-   Multiple-column compositions where useful

### Tablet

-   Reduced spacing
-   Flexible image ratios
-   Simplified navigation
-   Two-column layouts only where content supports them

### Mobile

-   Single-column layouts
-   Intentional content order
-   Readable typography
-   Large touch targets
-   Simple mobile navigation
-   Easy-to-find CTA
-   No clipped headings
-   No horizontal overflow

### Responsive QA Checklist

-   No horizontal scrolling
-   No clipped text
-   No overlapping content
-   No broken images
-   No layout jumps
-   No inaccessible content
-   No broken buttons
-   No broken forms
-   No unexpected spacing
-   No unreadable text
-   No desktop layout compressed awkwardly

## 27. Implementation Rules for AI Agent

### Before Coding

1.  Inspect the existing project.
2.  Inspect the existing website structure.
3.  Locate the current design system.
4.  Review existing typography.
5.  Review existing color tokens.
6.  Review current components.
7.  Review responsive behavior.
8.  Review accessibility.
9.  Review existing content and business logic.
10. Create a short current design audit.

### During Implementation

-   Do not blindly rebuild the website.
-   Preserve strong existing sections.
-   Fix root causes rather than applying random visual patches.
-   Use existing design tokens where possible.
-   Avoid unnecessary dependencies.
-   Do not invent business claims.
-   Do not change pricing or business logic.
-   Do not change forms, checkout, APIs, authentication, CRM, or
    integrations unless required for a UI/UX issue.
-   Keep all important text visible and readable.
-   Avoid excessive cards and decorative effects.
-   Use intentional layout variation.
-   Maintain the Dev Elite Interiors identity.

### After Implementation

Test:

-   Desktop
-   Laptop
-   Tablet
-   Mobile
-   Small mobile

Verify:

-   Text visibility
-   Typography
-   Spacing
-   Responsive behavior
-   Navigation
-   Buttons
-   Forms
-   Images
-   Accessibility
-   Performance
-   Animation
-   Existing functionality

### Final Report Must Distinguish

-   Implemented
-   Tested
-   Verified
-   Not verified

Do not claim success based only on code changes.
